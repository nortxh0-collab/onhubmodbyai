# VexxuzzZx HUB

Purple Glassmorphism UI dengan branding VexxuzzZx dan font MADE Evolve Sans EVO.

## Struktur UI
- FARM: hanya panel farming.
- EGG: hanya panel telur.
- SISTEM: konfigurasi dan informasi UI.
- Kartu menggunakan background JPG URL melalui helper asset executor bila tersedia.
- Bahasa UI utama: Indonesia.

## Font
`MADEEvolveSansEVO.ttf` digunakan otomatis jika executor menyediakan `getcustomasset`.

## Catatan
Package ini memisahkan dan menata UI. Fitur gameplay/server-authoritative tetap bergantung pada implementasi game dan API yang tersedia; UI tidak menjamin bypass atau exploit tertentu.
